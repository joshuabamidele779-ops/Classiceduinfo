Question review

  1. If 3x − 7 = 2x + 5, what is the value of x?

    • A 2
    • B 12
    • C −2
    • D 5

    Correct

    Collect like terms: 3x − 2x = 5 + 7, so x = 12.

  2. Simplify: (a² − b²) ÷ (a + b)

    • A a + b
    • B a − b
    • C a² + b
    • D 1

    Wrong Correct answer: B

    a² − b² factorises to (a + b)(a − b). Cancelling (a + b) leaves a − b.
